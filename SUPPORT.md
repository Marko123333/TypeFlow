# Поддержать TypeFlow

TypeFlow развивается как бесплатный проект с открытым исходным кодом.
Платежный сервис пока не подключен, поэтому лучший способ поддержать разработку:

1. Поставить проекту [звезду на GitHub](https://github.com/Marko123333/TypeFlow).
2. Рассказать о нем тем, кому нужен локальный переключатель русской и английской раскладки.
3. Прислать воспроизводимый пример ошибочного переключения через [GitHub Issues](https://github.com/Marko123333/TypeFlow/issues/new/choose).
4. Предложить исправление через pull request.

Когда появится официальный способ финансовой поддержки, ссылка будет опубликована здесь.

## Support TypeFlow

TypeFlow is a free and open-source project. No payment provider is configured yet.
You can help by starring and sharing the repository, reporting reproducible correction cases,
or contributing a pull request.
