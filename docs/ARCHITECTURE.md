# Архитектура

## Поток одного слова

~~~text
CGEventTap
  -> буфер физических клавиш
  -> граница слова
  -> политика безопасности и исключения
  -> образы слова в текущей и второй раскладке
  -> словарная оценка языка
  -> безопасная опечатка / регистр / е-ё
  -> замена через Unicode-события
  -> смена раскладки при необходимости
  -> возможность ручной отмены
~~~

Содержимое текстового поля не читается при обычном наборе. Для последнего слова
хранятся физические keyCode и флаги Shift/Caps Lock. Это позволяет полностью
заменить образ клавиш, включая пример, где русская заглавная Б выглядит как
символ < в английской раскладке.

Выделенный текст является отдельным fallback-путем через Accessibility и
буфер обмена. Буфер восстанавливается после операции.

## Жесты Shift

Один и двойной тап нельзя надежно реализовать двумя независимыми хоткеями.
ShiftGestureRecognizer держит первый тап в течение 280 мс:

- второй Shift в окне отменяет одиночное действие и запускает конвертацию;
- обычная клавиша в окне немедленно применяет смену раскладки до ее доставки;
- Shift, удерживаемый вместе с буквой, считается обычным вводом заглавной;
- одновременное нажатие левого и правого Shift имеет отдельное действие.

Алгоритм не зависит от AppKit и покрыт модульными тестами.

## Словарный скоринг

Автоматическое решение не складывает все словари в один огромный набор. У
каждого положительного сигнала есть сила:

1. Явно отобранные технические термины, включая `ssh`.
2. Системный локальный AppleSpell.
3. Большие fallback-корпуса: 2 323 330 русских и 148 957 английских форм.

Раскладка меняется только когда сигнал сконвертированного слова сильнее сигнала
набранного. Благодаря этому широкий русский корпус помогает с редкими словами,
но не может перевесить нормальное слово, подтверждённое AppleSpell.

Большие словари хранятся как отсортированные 64-битные хеши и отображаются в
память через `mmap`. Двоичный поиск не создаёт миллионы объектов `String` и не
блокирует обработчик клавиатуры длительной загрузкой.

## Решение по слову

Порядок важен:

1. Отсечь Secure Input, менеджеры паролей и пользовательские исключения.
2. Получить слово в обеих раскладках по физическим клавишам.
3. Применить только однозначные исправления регистра и е/ё в текущем языке.
4. Проверить, является ли второй образ известным словом.
5. Если раскладка верна, допустить только одноредакторную опечатку из локального
   системного словаря.
6. Сохранить замену для немедленной ручной отмены и обучения.

## Словари

Большой RU/EN fallback отображается в память и используется без полного
распаковывания. Ресурс е/ё загружается в utility-задаче, а не на потоке event
tap. Все словари полностью локальные:

- safe - разрешенная автоматическая замена;
- not_safe - кандидат плюс форма с е, что принудительно делает решение
  неоднозначным;
- пользовательские правила в будущем будут иметь высший приоритет.

## Безопасность

- Secure Input полностью останавливает обработку;
- менеджеры паролей исключены жестко и не могут быть удалены из списка;
- события, созданные приложением, помечаются и повторно не обрабатываются;
- журнал не содержит набранных символов;
- телеметрии и сетевой обработки текста нет;
- обновления принимаются только по detached-подписи постоянного сертификата
  TypeFlow, с проверкой SHA-256, подписи приложения, Bundle ID и версии;
- перед заменой приложения сохраняется проверенная копия для отката;
- self-signed канал не заменяет Developer ID и нотарификацию Apple при первой
  установке.
