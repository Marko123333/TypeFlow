# TypeFlow

Нативный локальный переключатель раскладки для macOS. Цель проекта - добиться
точности и удобства Caramba Switcher, не копируя закрытый код, название или
графику продукта.

Проект находится в активной разработке. Первая версия ориентирована на пару
русский + английский и macOS 13+; M1/M2/M3/M4 поддерживаются нативно.

## Скачать и установить

**[Скачать последнюю версию для macOS](https://github.com/Marko123333/TypeFlow/releases/latest/download/TypeFlow-macOS-arm64.dmg)**

1. Откройте скачанный `TypeFlow-macOS-arm64.dmg`.
2. Перетащите TypeFlow в Applications.
3. В том же окне дважды нажмите Applications, затем откройте TypeFlow в папке "Программы".
4. Если macOS заблокирует запуск, откройте "Системные настройки" → "Конфиденциальность и безопасность" и нажмите "Все равно открыть". Кнопка появляется после первой попытки запуска.
5. Следуйте двум пояснениям приложения для выдачи Accessibility и Input Monitoring.

После запуска иконка появится в строке меню macOS. Обычного окна и значка в Dock у приложения нет.

## Что уже работает

| Действие | Результат |
|---|---|
| Один короткий Shift | Переключить активную раскладку |
| Двойной Shift | Исправить последнее слово или выделенный текст |
| Оба Shift одновременно | Приостановить или возобновить автокоррекцию |
| Набрать тщвуюоы | Исправить на node.js, сохранив внутреннюю точку |
| Набрать htcthx или gjhtcthxb | Исправить на ресерч или поресерчи |
| Набрать BB или ФШ | Исправить на ИИ или AI |
| Набрать GHBDTN | Исправить на ПРИВЕТ через словарь верхнего регистра |
| Набрать ac, или ;r[ | Исправить на фсб или жкх |
| Набрать фсб, или жкх | Оставить русский текст и пунктуацию без изменений |
| Набрать ПРивет или WOrld | Исправить случайную вторую заглавную |
| Набрать елка | Исправить на ёлка и тд |
| Набрать все, осел или небо | Не угадывать е/ё без контекста |

Дополнительно:

- автоматическое определение неправильной раскладки на границе слова;
- локальная коррекция одноредакторных опечаток и переставленных соседних букв;
- 2 323 330 русских и 148 957 английских словоформ в компактных fallback-словарях;
- 106 657 безопасных и 33 686 неоднозначных русских словоформ с ё;
- пользовательские списки "всегда исправлять" и "никогда не исправлять";
- безопасное распознавание составных технических имен (`node.js`, `socket.io`, `asp.net`) без общего правила для доменов;
- распознавание коротких русских слов и более 1 700 русских аббревиатур в любом регистре;
- современная IT-, продуктовая, медийная и ИИ-лексика с русскими падежами, приставками и глагольными формами;
- словарное распознавание слов в нижнем, начальном заглавном и верхнем регистре без дублирования словарей;
- обучение после ручной отмены ошибочной автозамены и сессионный отказ от коррекции после удаления результата;
- ручная конвертация последнего слова, строки и выделенного текста;
- запоминание раскладки по приложениям;
- работа без телеметрии и облачной отправки набранного текста;
- подписанная проверка и установка обновлений с резервной копией для отката;
- пауза при Secure Input и жесткие исключения для менеджеров паролей;
- исключения для терминалов и IDE;
- поддержка Apple Screen Sharing в отдельном режиме.

## Сборка

Нужны macOS 13+ и Swift 6 из Xcode Command Line Tools.

~~~bash
cd macos
swift test
./build_app.sh
open TypeFlow.app
~~~

Локальная сборка и публичный DMG создают `TypeFlow.app`. Отдельный служебный
образ временно содержит `LocalSwitcher.app` только для совместимости со
встроенным апдейтером версии 0.1.11.

Локальная сборка по умолчанию подписывается ad-hoc и имеет архитектуру текущего
Mac. Релизы встроенного канала собираются постоянным сертификатом проекта через
`./create_dmg.sh --self-signed`; скрипт также обновляет SHA-256 и подписывает
манифест закрытым ключом из Keychain. Для universal-сборки нужен полный Xcode и
`RS_UNIVERSAL=1`. Developer ID и нотарификация Apple пока недоступны, поэтому
при первой установке macOS показывает предупреждение о неизвестном разработчике.

Версия 0.1.10 и более ранние сборки еще не содержат активный updater, поэтому
переход на 0.1.11 выполняется один раз вручную из DMG. Начиная с 0.1.11 кнопка
"Проверить обновления" умеет скачать, проверить, установить и перезапустить
приложение без Apple Developer Program.

После первого запуска macOS попросит:

1. Accessibility - для замены текста и работы с выделением.
2. Input Monitoring - для распознавания физических нажатий.

Пароли и поля с Secure Input не обрабатываются.

## Структура

- macos/Sources/SwitcherCore - тестируемые алгоритмы без UI;
- macos/Sources/TypeFlow - AppKit-приложение и интеграция с macOS;
- macos/Tests - модульные тесты распознавания жестов и коррекции;
- scripts/build_dictionaries.py - воспроизводимая сборка словарных ресурсов;
- docs/RESEARCH.md - проверенные функции Caramba и открытые источники;
- docs/ARCHITECTURE.md - поток событий и границы безопасности;
- docs/UPDATE_SECURITY.md - модель доверия и выпуск обновлений;
- THIRD_PARTY_NOTICES.md - лицензии и происхождение компонентов.

## Происхождение и лицензии

TypeFlow основан на MIT-проекте
[rashn/RuSwitcher](https://github.com/rashn/RuSwitcher). История Git и исходное
уведомление об авторских правах сохранены. Словари е/ё получены из MIT-проекта
[e2yo/eyo-kernel](https://github.com/e2yo/eyo-kernel). Большие fallback-словари
собраны из Russian Spelling Dictionary (MPL-2.0) и English Speller Database
(бывший SCOWL); точные версии и лицензии перечислены в THIRD_PARTY_NOTICES.md.

Исходный код распространяется по MIT License. Подробности находятся в
[LICENSE](LICENSE) и [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

TypeFlow не связан с Caramba Switcher и не использует его закрытый код.
